# Khac phuc loi nut PUSH_TO_GITHUB.bat tu dong dong

1. Giai nen toan bo ZIP vao mot thu muc binh thuong, vi du `C:\Users\admin\Downloads\Deepfake_Scanner_V5_Advanced`.
2. Khong chay file BAT truc tiep ben trong cua so ZIP nen.
3. Mo `PUSH_TO_GITHUB.bat` bang double-click. Script se mo PowerShell, hien tung buoc va luon giu cua so lai sau khi thanh cong / that bai.
4. Khi duoc hoi, nhap chinh xac `PUSH` (chu hoa) de xac nhan. Nhap khac hoac de trong se huy.
5. Neu loi, doc file `PUSH_TO_GITHUB_LOG.txt` nam cung thu muc voi file BAT va gui noi dung / anh loi.

Script su dung nhanh rieng `release/v5.0.1-localhost-ready-20261104`; khong push vao `main` va khong kich hoat deploy production qua thao tac nay. File `.env`, `.npmrc`, thu muc dependency va cac file khoa rieng duoc loai tru / kiem tra truoc commit.
